個人ブログを開設してみた

誕生日だからというわけではないんですが、タイトルの通り、個人ブログを開設してみました。

技術スタック的には GitHub Pages + Gatsby で、 ほぼ GatsbyとGitHub Pagesで作るMarkdownブログ の引き写しです。ここからスタイルとか弄っていけたらいいなと思ってるけどフロントエンド何も分からないマンなので一旦このまま公開。

公開の動機としては、 Google I/O のまとめとか、 外部の技術記事サイトではちょっとやりにくい部分をやっていける場所が欲しかったというのと、あまりにも色々な場所に技術記事を書き散らばしすぎたのでまとめたい欲が出てきたのでした。 Medium や Qiita に書いた記事はそのうちここにまとめていきたいなと思っています。（ Zenn は続けたい）

これからよろしくお願いします。
